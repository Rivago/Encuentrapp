# Encuentrapp

Encuentrapp es el prototipo de una aplicación web universitaria para registrar, localizar y recuperar objetos perdidos dentro del campus.

## Objetivo

Facilitar el registro y la búsqueda de objetos perdidos, permitiendo que los usuarios consulten información y den seguimiento a una solicitud de recuperación.

## Funciones principales

- Registrar objetos perdidos.
- Registrar objetos encontrados.
- Buscar objetos por sus características.
- Consultar información de un objeto.
- Solicitar su recuperación.
- Consultar el estado de una solicitud.
